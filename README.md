# Guia de Boas Práticas - InovaWeb

**Autor(a):** Yuji De Barros Couto Moura

## Sobre o Projeto
Este repositório contém o manual de boas práticas digitais desenvolvido especialmente para os clientes da agência InovaWeb. O objetivo deste guia é orientar sobre o uso correto de ferramentas, segurança online, estruturação de conteúdo e estratégias para manter uma presença digital profissional e otimizada.
